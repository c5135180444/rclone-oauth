# Privacy Policy

Last updated: October 21, 2026

This OAuth client ("rclone personal backup client") is used only by its owner, for the owner's own Google account. It is not offered to anyone else.

- The app uses Google Drive API access solely to copy the owner's own files from the owner's computer to the owner's own Google Drive.
- - No data is collected, stored, sold, or shared with any third party. Data moves only between the owner's computer and the owner's Google Drive.
  - - OAuth tokens are stored only on the owner's computer, in the local rclone configuration file.
    - - Access can be revoked at any time at https://myaccount.google.com/permissions.
     
      - The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
